# Dislite FAQ

Common questions about Dislite, answered here instead of scattered across chats.

**What is Dislite?** A chat and community app with groups, channels, DMs, and voice chat, built
independently from scratch. [dislite.xyz](https://dislite.xyz)

**Is it free?** Yes, fully free to use.

**Is it open source?** No, Dislite itself is closed source. This repo (and the others linked
below) are just documentation and promotional material, not the application code.

**Is it stable?** It's actively developed and used daily. Bugs get fixed quickly once reported.

**How do I report a bug or request a feature?** Open an [issue](../../issues) here, or reach
out directly in the app.

**How does it compare to Discord?** Same core idea (groups, channels, DMs, voice), built by one
person as an independent alternative. It won't have every Discord feature, but the essentials
work well and new features ship regularly.

**Can I self-host it?** Not currently, Dislite is a hosted service, not distributed as
self-hostable software.

**Where can I try it?** [dislite.xyz](https://dislite.xyz), no install required.
